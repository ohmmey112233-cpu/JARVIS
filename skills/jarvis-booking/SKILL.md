# การจอง

> ⚠️ **สถานะปัจจุบัน: ยังโทรจริงไม่ได้** — Phase 3 ค่อยต่อ Twilio/Vapi เข้ามา
> ตอนนี้ทำได้แค่บันทึกคำขอจองและเตรียม "ซองคำตอบล่วงหน้า" ไว้
> **ห้ามบอกโอมว่าจองให้แล้ว** ให้บอกตรงๆ ว่าบันทึกไว้ก่อน ยังโทรไม่ได้

## ประเภทที่รองรับ

`restaurant` · `eyebrow` · `laser` · `hotel` — ใช้ tool กลางตัวเดียว ไม่แยกตามประเภท

```bash
cd ~/jarvis && PYTHONPATH=jarvis python3 -m cli booking places --kind restaurant
cd ~/jarvis && PYTHONPATH=jarvis python3 -m cli booking create \
    --kind restaurant --place "ร้าน X" --date 2026-08-21 --time 18:00 \
    --party-size 4 --fallback "19:30,20:00"
```

ไม่ระบุ `--place` → ใช้ร้านประจำของประเภทนั้นจาก `favorite_places`

## ซองคำตอบล่วงหน้า — ถามก่อนโทร ไม่ใช่ถามกลางสาย

นี่คือกลไกหลักที่ spec เลือกไว้ ก่อนจะโทร ให้ถามโอมด้วยปุ่มกดว่า

> ถ้า 18:00 เต็ม เอา [19:30] [20:00] [ไม่เอา ให้โทรกลับมาถาม]

แล้วส่งคำตอบเข้า `--fallback` เพื่อให้ AI ตัดสินใจเองได้ในกรอบที่โอมให้ไว้

**ต้องมีตัวเลือก "ไม่เอา ให้โทรกลับมาถาม" ทุกครั้ง** — โอมต้องมีทางปฏิเสธการตัดสินใจ
ล่วงหน้าเสมอ ห้ามบังคับให้เลือกแค่ในตัวเลือกที่เราเสนอ

## ความซื่อสัตย์ (ข้อนี้สำคัญกว่าความสะดวก)

- รายงานว่า "จองสำเร็จ" ได้ต่อเมื่อยืนยันจริงแล้วเท่านั้น
- จองไม่ได้ให้บอกว่าจองไม่ได้ พร้อมเสนอทางเลือก **ห้ามกลบเกลื่อน**
- ยังไม่ได้โทร = ยังไม่ได้จอง พูดให้ตรงตามนั้น
