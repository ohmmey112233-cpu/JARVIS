# Gate Trial — ตัวตัดสินว่าจะใช้ Hermes หรือสร้างเอง

> อ้างอิง `jarvis-build-spec-v3.md` ส่วน Phase 0B ข้อ 2
> ใช้เวลา **3 วัน** (ต้องใช้ 3 วันจริงๆ เพราะข้อ 2 ต้องดู digest 3 เช้าติด)

## กติกา

ทดสอบ 3 ข้อ **ต้องผ่านครบทั้ง 3** ถึงไปต่อด้วย Hermes

| ผล | แปลว่า | ทำอะไรต่อ |
|---|---|---|
| ผ่านครบ 3 ข้อ | **Track A** | ใช้ Hermes เป็นฐาน → เริ่ม Phase 1 |
| ตกข้อใดข้อหนึ่ง | **Track B** | สร้างเองตาม spec v2 เดิม |

งาน Phase 1-5 เหมือนกันทั้งสอง track ต่างแค่ฐานข้างล่าง — ตกไม่ได้แปลว่าเสียเวลาเปล่า

**อย่ารัน `hermes update` ระหว่าง 3 วันนี้** เวอร์ชันที่ทดสอบถูกบันทึกไว้ที่ `~/.hermes/jarvis-version.lock` แล้ว ถ้าอัปเดตกลางคันแล้วผลเปลี่ยน จะแยกไม่ออกว่าเป็นเพราะ Hermes หรือเพราะการอัปเดต

## ข้อ 1 — คุยไทยลื่นไหม

**ทดสอบอะไร:** ไม่ใช่ว่า Claude พูดไทยเก่งไหม (เก่งอยู่แล้ว) แต่ทดสอบว่า **ตัว framework ทำภาษาเพี้ยนหรือเปล่า** จุดที่มักพังคือ Telegram ใช้ MarkdownV2 ซึ่งต้อง escape อักขระพิเศษ ถ้า escape พลาดจะเห็น backslash โผล่กลางประโยคไทย หรือข้อความหาย

**วิธีทำ:** ทักบอทใน Telegram ทีละข้อ แล้วดูผลที่ **หน้าจอ Telegram** (ไม่ใช่ใน log)

| # | พิมพ์ไปแบบนี้ | ผ่านเมื่อ | ผล |
|---|---|---|---|
| 1.1 | `สวัสดี ช่วยแนะนำตัวสั้นๆ หน่อย` | ตอบไทยล้วน อ่านรู้เรื่อง ไม่มี `\` แปลกปลอม | ☐ |
| 1.2 | `พรุ่งนี้วันอะไร วันที่เท่าไหร่ ตอบเป็นไทย` | วัน/วันที่ถูก **ตามเวลาไทย** ไม่ใช่ UTC | ☐ |
| 1.3 | `ช่วยจองโต๊ะร้าน Sushiro สาขา Central Festival เชียงใหม่ 4 คน 18:30 — ยังไม่ต้องจองจริง แค่ทวนกลับมาว่าเข้าใจว่าอะไร` | ทวนชื่อร้านอังกฤษถูก ไม่กลายเป็นภาษาไทยมั่ว ตัวเลข/เวลาไม่เพี้ยน | ☐ |
| 1.4 | `เขียนรายการของที่ต้องซื้อ 8 อย่างเป็นภาษาไทย ใส่หัวข้อย่อยด้วย` | bullet แสดงผลถูก สระ/วรรณยุกต์ไม่หลุด ไม่มีอักขระ escape โผล่ | ☐ |
| 1.5 | `อธิบายเรื่อง TCAS ให้ฟังยาวๆ สัก 300 คำ` | ข้อความยาวไม่ถูกตัดกลางคัน ถ้าแบ่งหลายข้อความก็ต่อกันได้ไม่ขาดตอน | ☐ |
| 1.6 | `ราคา 1,250.50 บาท ลด 15% เหลือเท่าไหร่ ตอบเป็นไทย` | คำนวณถูก เครื่องหมาย `.` `,` `%` แสดงปกติ ไม่มี `\` นำหน้า | ☐ |

**เกณฑ์ผ่าน:** ผ่าน 6/6 — ข้อ 1.6 กับ 1.4 คือตัวจับ escape พลาดโดยตรง ถ้าเห็น `\.` หรือ `\-` โผล่ในข้อความ = **ตก**

> **ถ้าเจอ `\` โผล่:** Hermes ส่งข้อความสุดท้ายเข้า Telegram แบบ MarkdownV2 ซึ่งต้อง escape อักขระอย่าง `.` `-` `!` `(` `)` ให้ถูก ถ้าเห็น backslash ค้างในข้อความ = ตัว framework escape พลาด ไม่ใช่ความผิดของ Claude — **นี่คือสิ่งที่ข้อนี้ตั้งใจจับ ให้ถือว่าตก** แต่ก่อนสรุปให้ทดสอบซ้ำอีกรอบ และจดไว้ว่าพังกับอักขระตัวไหนบ้าง จะได้แจ้ง issue ต้นน้ำที่ github.com/NousResearch/hermes-agent/issues หรือใช้เป็นข้อมูลตัดสินใจ Track B

## ข้อ 2 — digest เช้า 06:20 เวลาไทย มาตรง 3 วันติด

**ทดสอบอะไร:** scheduler ยิงตรงเวลาไทยจริงไหม และยิง **ทุกวันติดกัน** ไม่ใช่วันแรกมาแล้วหายไป (process ตาย/หลุด session)

**ตั้งไว้แล้วโดย** `scripts/gate-trial-setup.sh` — job ชื่อ `jarvis-gate-digest`

ตรวจก่อนนอนคืนแรกว่าเวลาถัดไปถูก:
```bash
hermes cron list | grep -A4 jarvis-gate-digest
```
บรรทัด `Next run:` **ต้องลงท้ายด้วย `+07:00`** ถ้าเป็น `+00:00` แปลว่า timezone ผิด digest จะมา 7 โมงเช้าไทยแทน — หยุดแล้วแก้ก่อน

| วัน | วันที่ | เวลาที่ข้อความถึงจริง | ตรงไหม (±5 นาที) | ภาษาไทยปกติไหม |
|---|---|---|---|---|
| 1 | ____ | ____ | ☐ | ☐ |
| 2 | ____ | ____ | ☐ | ☐ |
| 3 | ____ | ____ | ☐ | ☐ |

**เกณฑ์ผ่าน:** มาครบ 3/3 วัน และคลาดเคลื่อนไม่เกิน 5 นาที

> ถ้าวันไหนไม่มา อย่าเพิ่งตัดสินว่าตก — เช็คก่อนว่า gateway ล่มหรือเปล่า:
> ```bash
> hermes gateway status
> journalctl --user -u hermes-gateway --since "06:00" --no-pager | tail -40
> hermes cron runs                      # ดูประวัติว่ายิงจริงไหม
> ```
> ถ้า gateway ตายเพราะ VPS รีบูตแล้วไม่ขึ้นเอง = ปัญหา lingering ไม่ใช่ปัญหา Hermes
> แก้ `sudo loginctl enable-linger $USER` แล้ว **เริ่มนับ 3 วันใหม่**

## ข้อ 3 — คุมความจำได้เต็มรูปแบบ

**ทดสอบอะไร:** สั่งจำ/แก้/ลบ/ดู ผ่านแชทแล้ว **ผลตรงตามสั่งจริง** ไม่ใช่แค่บอทตอบว่า "จำแล้วครับ" แต่ไม่ได้จำ

**สำคัญ:** ทุกข้อต้องเช็ค 2 ชั้น — (ก) บอทตอบว่าอะไร (ข) ไฟล์ความจำเปลี่ยนจริงไหม

ดูไฟล์ความจำจริงด้วยคำสั่งนี้บน VPS:
```bash
cat ~/.hermes/memories/MEMORY.md 2>/dev/null || find ~/.hermes -name 'MEMORY.md' -exec cat {} +
```

### เกณฑ์ผ่าน

- **ข้อบังคับ (ตกข้อใดข้อหนึ่ง = ตกทั้งข้อ 3):** 3.1, 3.2, 3.4, 3.5, 3.7, 3.8
- **ข้อผ่อนผัน:** 3.6 (ถามยืนยันก่อนลบ) และ 3.9 (กู้คืน) — ถ้าทำไม่ได้ ยัง**ไม่ตก** แต่ต้องไปเขียนกลไก trash เองใน Phase 1 จดไว้ว่าเป็นหนี้งาน

> **ถ้าตกข้อ 3** spec เขียนทางออกไว้แล้ว: ไม่ต้องทิ้ง Hermes ทั้งตัว — เปลี่ยนไปเก็บ lessons เป็นไฟล์ markdown ใน **Obsidian vault** (`vault/lessons/` ไฟล์ละเรื่อง, ลบ = ย้ายเข้า `vault/trash/`) แล้วใช้ Hermes เป็นแค่ runtime ที่อ่าน/เขียนไฟล์ในนั้น
> — ทางนี้ยังนับเป็น **Track A** ได้ ให้จดในสรุปว่าเลือกทางนี้
